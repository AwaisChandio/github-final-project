# Simple Interest Calculator

A capstone project created as part of the Introduction to Git and GitHub course. 

## Project Overview
This repository contains a simple Bash script (`simple-interest.sh`) that calculates simple interest based on user inputs:
- Principal amount
- Annual rate of interest
- Time period in years
